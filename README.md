# Sonora

Aplicacion musical creada con React, TypeScript, Vite y Tailwind CSS.

## Requisitos

- Node.js 20 o superior
- pnpm

## Instalar

Desde la raiz del proyecto:

```bash
pnpm install
```

## Ejecutar

```bash
pnpm dev
```

Vite mostrara en la terminal la URL local, normalmente:

```text
http://localhost:5173
```
